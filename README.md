# 🌌 Star Trash

Um jogo em **pixel art** desenvolvido com **Godot 4.5.1**, focado em compatibilidade com **PC e dispositivos móveis modestos**.  
Este repositório contém todo o código-fonte, assets e documentação do projeto.

---

## 🎮 Sobre o Projeto
**Star Trash** é um jogo 2D experimental que busca unir simplicidade gráfica com jogabilidade divertida.  
O objetivo é criar uma experiência leve, acessível e otimizada para rodar em diferentes plataformas.

---

## 🚀 Tecnologias Utilizadas
- [Godot Engine 4.5.1](https://godotengine.org/)  
- Pixel Art (sprites e cenários)  
- GDScript para lógica do jogo  
- Git + GitHub para versionamento e colaboração  

---

## 📂 Estrutura do Projeto
- `scenes/` → Cenas principais do jogo  
- `sprites/` → Arte em pixel art  
- `scripts/` → Código em GDScript  
- `docs/` → Documentação e materiais auxiliares  

---

## 🛠️ Como Rodar
1. Instale a [Godot 4.5.1](https://godotengine.org/download).
2. Clone este repositório:
   ```bash
   git clone https://github.com/KatchauXD/star-trash.git
3. Abra a pasta star-trash na Godot.
4. Clique em **Play** para executar o jogo.
